# RTV Field Data

This repository contains data from a double-blinded, placebo-controlled evaluation of a transmission blocking reservoir targeted vaccine (RTV) against Borrelia burgdorferi, conducted in Maryland, USA.

The study evaluated the effectiveness of RTV on B. burgdorferi transmission over five years by monitoring mice, ticks collected from mice, ticks collected by drag sampling, and dogs across seven field sites.

### Variables Included

_`Year`_: Observation year (2020–2024);

_`Site`_: Field site identifier;

_`Group`_: Intervention assignment (RTV or Ctrl);

_`Location`_: Geographic region;

**Dog Data**

_`Positive_dogs`_: Number of dogs that tested positive for seroconversion;

_`Num_tested_dogs`_: Total number of dogs tested;

**Mouse Data**

_`Positive_mice`_: Number of mice that tested positive for B. burgdorferi;

_`Num_tested_mice`_: Total number of mice tested;

_`Positive_protection`_: Number of mice that tested positive for OspA antibodies;

_`Num_tested__protection`_: Total number of mice tested for antibodies;

**Tick Data (from Mice)**

_`Ticks_from_mice`_: Total number of ticks collected from mice;

_`Positive_ticks_mice`_: Number of ticks from mice that tested positive for B. burgdorferi;

**Tick Data (from Drag)**

_`Ticks_drag`_: Total number of ticks collected via drag sampling;

_`Positive_ticks_drag`_: Number of ticks from drag that tested positive for B. burgdorferi.
